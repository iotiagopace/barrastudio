# Barra Studio Criativo — Site institucional com portfólio CMS

Arquivos principais:

- `index.html`: site institucional estilo portfólio.
- `admin.html`: painel CMS para adicionar, editar e remover projetos.
- `assets/`: imagens renderizadas do PDF de portfólio enviado.

Acesso ao painel:

- URL local: `admin.html`
- Senha: `barra2026`

Observação técnica: esta versão usa IndexedDB no navegador para salvar os projetos. Em produção, funciona bem para protótipo/local, mas para o cliente usar em múltiplos dispositivos o ideal é conectar o painel a um backend, Supabase, Directus, Firebase, n8n + banco, ou API própria.
