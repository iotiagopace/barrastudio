# Barra Studio Criativo — Site Institucional + CMS

Projeto de site institucional em formato de portfólio para o **Barra Studio Criativo**, escritório de arquitetura e engenharia especializado em projetos residenciais, comerciais, restaurantes, saúde e espaços corporativos.

A proposta do projeto é transformar o portfólio visual da marca em uma presença digital mais elegante, navegável e comercial, com foco em apresentação institucional, valorização dos projetos realizados e captação de novos contatos via formulário e WhatsApp.

## Visão geral

O site foi desenvolvido com uma estética minimalista e editorial, inspirada na identidade visual do Barra Studio Criativo: tons neutros, fundo claro, contraste com preto/chumbo, linhas finas, imagens em destaque e navegação fluida.

Além da página institucional, o projeto conta com um painel CMS simples para cadastro, edição e remoção de projetos do portfólio.

## Funcionalidades

- Site institucional estilo portfólio
- Seções de apresentação, processo, metodologia, áreas de atuação, equipe e contato
- Portfólio dinâmico com projetos cadastrados pelo painel
- Página/modal de detalhes do projeto
- Cadastro de múltiplas imagens por projeto
- Suporte a imagens de antes e depois
- Suporte a vídeos do YouTube
- Formulário de contato
- Botão flutuante de WhatsApp
- Ícones de Instagram e WhatsApp no rodapé
- Navegação suave entre seções
- Menu superior com efeito visual de hover
- Layout responsivo para desktop e mobile
- Painel administrativo simples para gestão dos projetos
